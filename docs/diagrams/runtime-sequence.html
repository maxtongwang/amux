A message reaches a worker and comes back

Time runs downward. An owner or peer worker sends a message; the API checks authority, pastes it into the worker pane, records it in the ledger and pushes it over SSE. The worker’s Stop hook later reports idle, which becomes a revisioned event and drains any queued messages.

Solid: call · Dashed: reply or push · Steps 10 and 11 run only when steering_queue holds rows (automated senders, selector or paused targets)
