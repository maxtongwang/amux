AMUX / SYSTEM DIAGRAMS / 2026-10-26

The server sits between callers and workers

Callers and workers reach one HTTP API that checks authority and stamps the true sender. A single-writer SQLite store records each change with a revision, and the same journal feeds the live stream back to the dashboard. Jobs and the orchestrator read the store and drive worker sessions.

Solid arrow: call, write or event · Burnt orange: server-verified authority boundary · Paths are under crates/amux-server/src unless shown
