AMUX / SYSTEM DIAGRAMS / 2026-10-24

One control plane, native worker sessions

The local Rust server owns coordination; native CLIs run in tmux panes. Delivery is separate from the worker execution backend.

The dashboard arrow to vault/grants denotes its API surface, not direct file access. The server serves the dashboard and streams updates via SSE. Hub and side panes share tmux infrastructure; they are not extra servers. Vault and grant files live under the Amux home, outside SQLite. Provider adapters supply launch/model behavior. Other providers and backends are omitted.
