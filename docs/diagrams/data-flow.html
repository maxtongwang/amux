AMUX / SYSTEM DIAGRAMS / 2026-10-26

Where amux data enters, rests and is read

Requests, hook reports and provider transcripts enter through the HTTP API, which writes domain rows and a revision journal to one SQLite file plus per-worker files. The dashboard reads back by SSE, delta sync and GET; the orchestrator and jobs poll the tables; prompts leave into worker panes.

Solid arrow: data moved or read · Burnt orange: server-verified request boundary · Paths are under crates/amux-server/src unless shown
