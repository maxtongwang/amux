Inputs, secrets and evidence take separate paths

Messages carry provenance. Status and audit records carry evidence. Secret values enter a process environment rather than a message body.

The worker-to-view arrow summarizes transcript/message capture; status hooks separately update reports and SSE. “Lead reads” means authorized access through existing CLI/API views, not an unrestricted cross-group broadcast. Vault resolution audits key names, scopes and versions only. tmux launch uses deferred environment injection; running workers keep old values until restart. Cards persist work and evidence; named signals clear waits on cards that explicitly chose that signal. Isolated workers retain owner transport/history and passive status, without automatic board capture.
